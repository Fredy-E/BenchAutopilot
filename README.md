# Bench Autopilot

Stdlib-only bench orchestration CLI. No dependencies, no network, no installs.

## Files

- `run.py` — the CLI (`python run.py --config sample.json`)
- `sample.json` — harmless sample config (echo/python one-liners only)
- `sample_artifact.txt` — fixture hashed by the sample manifest stage
- `test_run.py` — unittest suite (3 tests, RED-first)
- `receipt.sample.json` — generated by the sample run (gitignored in real use)

## Quick start (Windows)

```bat
cd next-build\autopilot
python run.py --config sample.json
python -m unittest test_run -v
```

Sample run prints rolling tails only and writes `receipt.sample.json`:

```jsonc
{
  "generated_at": "...",
  "config": "sample.json",
  "ok": true,
  "stages": [
    {"name": "static-checks", "exit": 0, ...},
    {"name": "build", "exit": 0, ...},
    {"name": "artifact-manifest", "exit": 0, "sha256s": {...}},
    {"name": "smoke-test", "exit": 0, ...}
  ]
}
```

The sample config touches nothing real: no hardware, no USB, no car,
no installs — only `python -c "print(...)"` one-liners plus a sha256
of `sample_artifact.txt`.

## Config schema

```jsonc
{
  "build_cmd": ["python", "-c", "print('...')"],  // used by type=build stages
  "defaults": {"timeout": 60, "tail_lines": 15},
  "receipt": "receipt.json",
  "stages": [
    {"name": "static-checks", "type": "exec", "cmd": [...], "timeout": 30},
    {"name": "build", "type": "build", "timeout": 120},       // cmd from build_cmd
    {"name": "artifact-manifest", "type": "manifest",
     "artifacts": ["path/to/file.bin"]},                       // sha256 each
    {"name": "smoke-test", "type": "exec", "cmd": [...], "timeout": 30}
  ]
}
```

- `type: build` uses `stage.cmd`, else top-level `build_cmd`, else a
  dry-run printer (`print('dry-run: no build command configured')`).
  The build command is **never hardcoded** — it always comes from config.
- `type: manifest` hashes `artifacts` (relative to the config dir);
  a missing file fails the stage.
- Per-stage `timeout` (seconds) overrides `defaults.timeout`.
- CLI flags `--receipt`, `--tail-lines`, `--timeout` override config.

## Semantics

- **Stop-on-first-failure:** a non-zero exit, timeout, or missing
  artifact ends the run; later stages are recorded as `"skipped"`.
- **Timeout scope:** expiry calls `Popen.kill()` on the owned child
  handle only — never `taskkill /IM` or any image-wide kill. The
  two-sleeper test (`test_timeout_kills_only_owned_child`) proves an
  unrelated sleeper survives the timeout.
- **Rolling tails + secret hygiene:** console and receipt keep only the
  last N lines (`tail_lines`, default 15); full output is never printed
  or persisted. `password=/secret=/token=/api-key=` patterns are
  replaced with `***REDACTED***` before display/storage.
- **Receipt:** `{"generated_at", "config", "ok", "stages": [...]}`;
  exec stages carry `name/type/cmd/exit/status/timed_out/started_at/
  ended_at/duration_s/tail`; manifest stages carry `sha256s/missing`.

## Real-machine use (owner-operated)

This tool only runs what the operator puts in the config, on the
operator's own bench machine. To wire a real bench:

1. Copy `sample.json` → `bench.local.json` (keep `.local` out of git).
2. Set `build_cmd` to the real build invocation, e.g.
   `["python", "build_firmware.py", "--board", "bench-revA"]`.
3. Point `artifact-manifest` at the real outputs
   (`["out/firmware.bin"]`) and `smoke-test` at the real smoke
   command with a conservative `timeout`.
4. Run `python run.py --config bench.local.json`, inspect the tail
   output and receipt, and keep the operator at the bench for the
   whole run. Nothing here drives hardware by itself — every effect
   comes from commands the owner explicitly configured.

Tests were written first against a stub (`print("stub")`, exit 0) and

- `test_failing_stage_stops_run`

- `test_receipt_contains_exact_hashes`

Run: `python -m unittest test_run -v` (stdlib only, Windows-safe).
